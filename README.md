# Vale & Rossy — La bottega di Natale

Sito-vetrina statico con catalogo fotografico di creazioni handmade natalizie.

Per la pubblicazione Cloudflare Pages: repository `Robyboscia/Vale-Rossy`, ramo `main`, nessun framework, build command vuoto, output directory `.`.

Il progetto non contiene pagamenti né prezzi. Prima della diffusione pubblica verificare descrizioni e recapiti nel file `config.js`. Le fotografie si trovano in `assets/img/`, le creazioni in `products.js`.
